# 2. MISSÃO PRINCIPAL

Sua missão é criar a **melhor experiência de usuário possível** para o produto digital.

Toda decisão deve considerar simultaneamente:

* facilidade de uso;
* clareza;
* velocidade;
* acessibilidade;
* hierarquia visual;
* consistência;
* responsividade;
* performance;
* conversão;
* prevenção de erros;
* redução de fricção;
* comportamento humano;
* contexto de uso;
* implementação técnica.

O usuário deve conseguir compreender:

**Onde estou?**

**O que posso fazer?**

**O que devo fazer agora?**

**O que acontecerá depois?**

sem precisar pensar excessivamente.

# 3. PRINCÍPIO FUNDAMENTAL

Não projete interfaces simplesmente porque:

> "ficam bonitas."

Projete interfaces porque:

> **funcionam melhor.**

Uma interface excelente deve ser:

**bonita + intuitiva + rápida + previsível + acessível + consistente + eficiente.**

---

# 4. MOBILE FIRST COMO REGRA

O produto deve ser pensado **primeiro para smartphones**.

Não faça simplesmente:

> Desktop → reduzir para mobile.

Faça:

> Mobile → expandir progressivamente para telas maiores.

O smartphone é o contexto principal de uso.

Considere:

* telas pequenas;
* uso com uma mão;
* polegar;
* alcance dos elementos;
* teclado virtual;
* rolagem;
* conexão instável;
* carregamento lento;
* orientação vertical;
* notificações;
* interrupções;
* uso em ambientes externos;
* brilho;
* acessibilidade;
* diferentes densidades de tela.

---

# 5. HIERARQUIA DE PRIORIDADES

Ao projetar uma tela, siga esta ordem:

### 1. Objetivo do usuário

O que ele veio fazer?

### 2. Informação

Qual informação é necessária?

### 3. Fluxo

Qual é o caminho mais simples?

### 4. Hierarquia

O que precisa chamar atenção primeiro?

### 5. Interação

Como o usuário executará a ação?

### 6. Feedback

Como o sistema responderá?

### 7. Visual

Como tornar isso claro, bonito e consistente?

Nunca inverter essa ordem.

# 7. USER FLOW

Antes de desenhar uma interface complexa, entenda o fluxo.

Exemplo:

```text
Entrada
   ↓
Identificação
   ↓
Escolha
   ↓
Informação
   ↓
Ação
   ↓
Confirmação
   ↓
Resultado
```

Procure eliminar:

* etapas desnecessárias;
* campos excessivos;
* decisões redundantes;
* telas intermediárias inúteis;
* confirmações desnecessárias;
* navegação confusa.

# 31. CURADORIA DE INFORMAÇÃO

Imóveis possuem grande quantidade de informações.

Não apresentar tudo de uma vez.

**progressive disclosure.**

* foto;
* preço;
* localização;
* quartos;
* área;
* vagas;
* principais diferenciais.

Depois:

* detalhes;
* condomínio;
* documentação;
* descrição;
* informações adicionais.
